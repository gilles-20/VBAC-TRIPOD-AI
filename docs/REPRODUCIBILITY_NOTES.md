# Reproducibility notes

## Data redistribution

Raw CDC/NCHS Natality files and derived person-level datasets are intentionally excluded from the repository.

## California sensitivity analysis

The public-use Natality microdata used for the analysis do not provide a record-level state identifier suitable for excluding California. Therefore a California-exclusion sensitivity analysis cannot be reproduced from these public-use files alone.

## Post-hoc analysis

The race/ethnicity-inclusive counselling model was fitted only after the final frozen 2024 race-neutral evaluation and must be interpreted as a post-hoc comparative/sensitivity analysis.

## Participant flow

The participant-flow reconstruction was run from the raw annual Natality public-use files and exactly reproduced the analytical cohort size of 772,741.
